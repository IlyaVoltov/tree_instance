# Как работает наша программа?
Создаём узлы — как карточки с надписями: «Чай», «Кофе», «Пиво».

- Соединяем их — добавляем одни карточки внутрь других.

- Печатаем структуру — показываем всё как дерево с отступами.

- Задаём вопросы — программа «спускается» по веткам, пока не дойдёт до листа.

Это называется рекурсия — когда функция вызывает саму себя. Как зеркало в зеркале!
